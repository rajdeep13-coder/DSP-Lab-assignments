This repository contains Digital Signal Processing lab practice and assignment scripts written in Octave/MATLAB.


- Assignment PDFs are stored in the `Assignments-pdf/` folder.

## How to use

### In Octave

1. Install Octave from the official site: https://octave.org/
2. Open Octave and set the working directory to this repo folder.
3. Run any script with:

```matlab
run('Problems on Two Dimensional Graphics/1.m')
```

You can also open a `.m` file directly in the Octave editor and click Run.

### In MATLAB

1. Install MATLAB from MathWorks or use MATLAB Online.
2. Sign in with your college ID or college email if your institute provides a campus license.
3. Add this repository folder to the MATLAB path or set it as the current folder.
4. Run a script using the editor Run button or:

```matlab
run('Familiarization with OCTAVE/1.m')
```

If your college has a MATLAB license, you may be able to activate access through your institution account. Check your college portal or MathWorks campus license page for the exact sign-in flow.

## Notes

- All scripts are plain `.m` files.
- Most files are small lab examples, so they can be run one at a time.
- Some scripts produce plots, so keep the figure window open after running them.
